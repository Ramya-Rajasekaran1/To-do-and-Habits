⏱️ 2. Lifecycle of a Real Task (Step-by-Step)

What happens inside the system during the 1.2 seconds between pressing Send on WhatsApp and seeing the block appear on your screen:

01
You Send a Message on WhatsApp
You text "Coffee tomorrow at 3pm for 45m" from your registered number +91 7708914559.
02
Twilio Catches It & Fires a Webhook POST
Twilio packages your text into a digital envelope (HTTP POST) and sends it across the internet to our live webhook at https://sycora.netlify.app/.netlify/functions/whatsapp.
03
Netlify Serverless Function Wakes Up (200ms)
Our cloud function spins up instantly from sleep, receives the text, and calls Google Gemini 2.5 Flash AI with our custom system prompt.
04
Gemini AI Extracts Structured JSON (550ms)
Gemini extracts clean computer data: { name: "Coffee", date: "2026-10-10", sm: 900, dm: 45, cat: "personal" }.
05
Supabase Inserts Row into PostgreSQL Database
The function inserts the task into the cloud tasks table using the secret service key, and sends a TwiML confirmation text back to your phone.
06
Realtime WebSockets Alerts the Desktop Dashboard
Supabase fires an instant INSERT push event through the open WebSocket tunnel (sb.channel('realtime-tasks')).
07
JavaScript Mutates State & Renders the Calendar Block
QuestLog adds the task to S.tasks, computes vertical position: (900 - 540) * 1px = 360px, renders the yellow block, and triggers a toast notification without any page reload!
🗄️ 3. Database Setup & The "Timeline Math" Secret

How our PostgreSQL database is structured and the clever mathematical trick that makes QuestLog's timeblocking 10x faster than traditional apps:

Column Name Data Type Example Value Designer Explanation
id uuid 3403159b-c349... Unique fingerprint for each task card.
user_id uuid 4a51d743-b441... Ties the task to your private login account.
name text "Coffee" Clean title displayed on the calendar card.
sm int (nullable) 900 Start Minute from midnight (3:00 PM = 900). Null = Unscheduled!
dm int 45 Duration Minutes (Determines card height on calendar).
cat text "personal" Category: work, health, learn, finance, personal.
done boolean false Checked state (true = completed & struck through).
created_for date "2026-10-10" Calendar day this task belongs to.
💡 Why We Use `sm` (Start Minute) Instead of Standard Dates:

Most calendar apps store dates like "2026-10-10T15:00:00.000Z", which require heavy date-parsing libraries to position items. QuestLog converts every time into Start Minute (`sm`):

• 9:00 AM (Grid Start) = 9 × 60 = 540
• 3:00 PM = 15 × 60 = 900
• Card Position Formula: top: (900 - 540) * 1px = 360px!
• Card Height Formula: height: dm * 1px = 45px!

Dragging, snapping, and resizing blocks becomes pure grade-school math that runs at 60 frames per second without lag!
